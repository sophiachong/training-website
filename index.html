Progression Rules

Progression Rules
Lift TypeHow to ProgressNotes
Main lower body lifts Add 2.5–5 kg when all reps are clean Squat, deadlift, RDL
Main upper body lifts Add 1–2.5 kg when all reps are clean Bench, OHP
Rows / split squat / pull work Add reps first, then add load Example: 3x6 → 3x7 → 3x8, then increase weight
Calves Stay in the range and push smooth reps No bounce-rep nonsense

If bar speed is ugly, hold the weight. This is a strength block, not an ego block.

How running fits during this block

  • Main idea: strength is the emphasis, but you are not abandoning aerobic fitness.
  • Most runs easy: keep them conversational and finish feeling better than you started.
  • Saturday Strength C: this is runner support work, not a sneaky fourth hard session.
  • Keep it tight: single-leg control, calves, core, and a little elasticity beat a laundry list of low-value fluff.
  • Sunday long run: long enough to keep the engine alive, not so long it trashes the gym week.
  • Transition phase: use this week to reduce lifting volume and start feeling ready for the 5K return-to-run block.

Why this block had a longer runway

  • More room to rebuild: eight focused strength weeks gave you space to recover after being sick without rushing the handoff.
  • The extra runway helped the handoff: rather than forcing the 5K block while you are still recovering, it gave you a cleaner runway into faster work.
  • Running still matters: the goal is to carry the strength into the 5K and 10K phases, not live in gym cave mode.
  • Longevity-friendly: strong, robust, and still aerobically fit is the point.
